## الطريقة

1. صفحة HTML محلية (`http://192.168.1.25:8899/p3.html`) تعرض `CLICK screenX*dpr, screenY*dpr` بعد كل نقرة (شريط أخضر + نقطة حمراء).
2. Chrome في مقدمة TECNO.
3. نقرات المشاهد عبر **مسار المنتج**: `screen:mouse_event` (نسبة 0..1) → سيرفر → وكيل → `dispatchGesture` عند بكسل الجهاز.
4. قراءة الرقم من شجرة UI ولقطة الشاشة. الخطأ = مسافة إقليدية بين المقصود والمُبلَّغ.

**قبل النقر:** a11y كان **معطّلًا** (`accessibility_enabled=0`) — فخّ 78. أُعيد تمكينه بالأمر الموثّق (بلا force-stop):
```
settings put secure enabled_accessibility_services com.airemote.agent/com.airemote.agent.AiRemoteA11y
settings put secure accessibility_enabled 1
```
بعده النقرات وصلت فورًا. السبب الأول لفشل r25 كان مزيج: a11y + عدم وجود هدف يُظهر الإحداثيات (uiautomator لا يرى محتوى Chrome بدون هذا الهدف).
