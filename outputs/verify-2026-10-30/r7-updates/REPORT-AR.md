## 1) نموذج الثقة (بلا توقيع حزمة)

| الطبقة | التفصيل |
|---|---|
| البيان | `manifest.json` موقَّع **Ed25519** + `manifest.sig` |
| المفتاح | **مثبَّت داخل الوحدة** (`SERVER_PUBLIC_KEY`) — لا يُقرأ من مجلد التوزيع، فامتلاك المجلد لا يكفي لتزوير بيان |
| الحزمة | **SHA-256** من البيان يُحسب محلياً + تطابق الحجم قبل أي تثبيت |
| النتيجة | أي فشل = تقرير بسبب واضح ولا شيء يُثبَّت |

## 2) التدفّق

`check` (قراءة فقط) → `apply` (`{version, confirm:true}`) → staging ← مساعد منفصل:
**يوقف السيرفر ← يثبّت `/S` ← يشغّله ← ينتظر `/health` بالإصدار الهدف ← إن لم يظهر يعيد تثبيت الحزمة الأقدم** ويكتب `success` / `rolled-back` / `failed` ليقرأها الإقلاع التالي.

**لماذا مساعد منفصل:** NSIS لا يستطيع استبدال ملفات يمسكها التنفيذي العامل؛ يُكتب `apply-update.cjs` في مجلد البيانات ويُشغَّل بـ`electron.exe` في وضع Node منفصلاً.
