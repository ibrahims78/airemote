## 1. ما تغيّر (ثلاث قطع مترابطة)

| # | الطبقة | التغيير |
|---|---|---|
| 1 | `capture.html` | `FULL_REFRESH_MS = 15000` بدل منطق «دلتا خلال 2 ثانية فقط». الشاشة الساكنة **لا ترسل شيئاً** بدل إرسال ~240KB كل 1.5s. الإطار الكامل صار أماناً دورياً كل 15 ثانية أو عند الطلب. |
| 2 | `capture.html` + `main.js` | استقبال `force-keyframe` من main وتعيين `forceFull` → إطار كامل فوري عند التحاق مشاهد. |
| 3 | `server.js` | عند التحاق مشاهد بجلسة قائمة: إعادة الإطار المخزَّن **و** إرسال `server:force_keyframe` للوكيل بنفس `sessionId`. |

**قبل / بعد في المنطق:**

```js
// قبل
if (d && d.none && (Date.now() - lastFullAt) < 1500) { …return }          // صمت 1.5s فقط
if (d && !d.none && region < 55% && sinceFull < 2000) mode = 'delta'      // دلتا خلال 2s فقط
// بعد
if (forceFull) mode = 'full'
else if (d.none) { if (sinceFull < 15000) return; mode = 'full' }         // صمت حتى 15s
else if (region < 55% && sinceFull < 15000) mode = 'delta'
```

## 4. تعديل هدف معلن (تصحيح ذاتي موثّق)

هدف R1 الأصلي «ساكن ≥ 8 fps» كان خاطئاً منطقياً: الشاشة التي لا تتغيّر لا يجب أن ترسل إطارات. الأهداف المعتمدة الآن:

| المؤشر | الهدف | المحقَّق |
|---|---|---|
| نطاق الساكن | ≤ 25 KB/s | **15.66** ✅ |
| نطاق النشط | ≤ 120 KB/s | **61.56** ✅ |
| متوسط الإطار النشط | ≤ 15 KB | **9.46** ✅ |
| نسبة الإطارات الكاملة (ساكن) | ≤ 0.35 | **0.286** ✅ |
| fps النشط | ≥ 12 (ظرف GUI) | **6.57** (nogui) ❌ مؤجّل |

**البند المفتوح:** هدف fps النشط يحتاج قياساً في ظرف `gui` (الـVM يعمل `nogui` بسبب قفل واجهة VMware)، وبعد بناء السيرفر الجديد. لا يُعلن استيفاؤه قبل ذلك.
