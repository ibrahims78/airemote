# R6 — شريحة 1: طابور النقل البصري

**التاريخ:** 2026-10-28 · **الحالة:** مُنفَّذ ومُتحقَّق (typecheck + build + تشغيل حقيقي)
**النطاق:** البند الأول من R6 — لوحة الطابور فوق `ft:progress` الذي سلّمته R5.

---

## 1. ما نُفِّذ

| العنصر | التفصيل |
|---|---|
| مكوّن `TransferQueue.tsx` | قسم قابل للطي داخل تبويب «الملفات»: شريط تقدم، حالة، بايتات، أزرار إيقاف/استكمال/إلغاء |
| رفع قابل للاستكمال من المتصفح | إنشاء نقل ← `start` ← دفع مقاطع 1MB ← `finish`؛ البصمة تُحسب في المتصفح للملفات ≤128MB |
| استكمال بعد إغلاق الصفحة | إعادة اختيار الملف ثم متابعة من `nextOffset` المحفوظ على السيرفر |
| سياسة التعارض | قائمة داخل اللوحة: إعادة تسمية / استبدال / تخطٍّ |
| حد السرعة | قائمة: بلا حد / 2 / 8 / 32 MB/s تُمرَّر كـ`speedLimitKbps` |
| التقدّم الحيّ | قناة `onTransferProgress` في `lib/websocket.ts` تستقبل `ft:progress` بلا مزاحمة `extraCallback`، مع polling احتياطي كل 2.5s |
| الوضعان الفاتح والداكن | أصناف `dark:` على كل عنصر؛ الألوان المتراكبة كانت داكنة فقط في المسودة الأولى |
| حالة عدم التوفّر | إن كان السيرفر المثبَّت بلا مسارات R5 تظهر رسالة صريحة بدل خطأ صامت |

## 2. التحقق (بالدليل)

| الفحص | النتيجة |
|---|---|
| `pnpm --filter @airemote/dashboard typecheck` | ✅ بلا أخطاء |
| `pnpm --filter @airemote/dashboard build` | ✅ 11.36s، الحزمة تحتوي المكوّن |
| أصناف السِمة في CSS النهائي | ✅ `index-*.css` يحوي `dark:bg-slate-900/40` و`dark:text-slate-200` |
| تشغيل حقيقي | سيرفر مصدر (R5) + وكيل وهمي + لوحة مبنية على `127.0.0.1:4180`، دخول فعلي، تبويب الملفات، اللوحة ظهرت بعنوان «نقل الملفات — 2 نشط · 3 عنصر» وصفوف الحالة |

**الملاحظة البصرية:** عُرضت اللوحة فعلياً في نافذة المتصفح (عرض 398px، الوضع الفاتح) بعنوان «نقل الملفات — 2 نشط · 3 عنصر» وصفوف الحالة بداخلها. اللقطة أُخذت قبل إعادة البناء النهائية فظهرت بالألوان الداكنة القديمة؛ أُصلحت الألوان وأُعيد البناء بعدها، وأُثبت وجود أصناف السِمة في CSS النهائي (الجدول أعلاه). لم تُحفظ اللقطة كملف.

## 3. حدود

1. **لم تُختبر الأزرار بصرياً بعد إعادة البناء** — نافذة المتصفح في هذه الجلسة أُغلقت قبل التقاط اللوحة الموسّعة؛ التحقق البصري الكامل بند في R6.
2. **الاستكمال بعد إعادة تحميل الصفحة يحتاج إعادة اختيار الملف** — قيد المتصفح (لا يملك مقبض الملف)، ويُعرض للمستخدم صراحةً.
3. **الدفعات (10,000 ملف) بلا واجهة** — الـAPI موجود؛ العرض البصري للدفعات مؤجّل.
4. **`ft:progress` يعتمد على مقبس اللوحة العام**؛ عند انقطاعه يعمل polling كل 2.5s.
