# R6 — شريحة 4: تحويل شاشة الأجهزة إلى المكتبة

**التاريخ:** 2026-10-28 · **الحالة:** مُنفَّذة ومُتحقَّقة (typecheck + build + لقطة شاشة)
**النطاق:** أول شاشة كاملة تُحوَّل إلى الرموز + المكتبة، مع الحالات الإلزامية الثلاث.

---

## 1. ما تغيّر

| العنصر | قبل | بعد |
|---|---|---|
| العنوان والوصف | `text-white` / `text-slate-400` | `text-ink` / `text-muted` |
| زر «إضافة جهاز» | زر بيدوي بأصناف | `Button variant="primary"` |
| نموذج الإضافة | حقل وزر بأصناف صريحة | `Card` + `CardBody` + `Input` + `Button` |
| التحميل | هيكل عظمي مكتوب يدوياً بـ`slate` | `Card` + `SkeletonRows rows={5}` |
| الخطأ | **غير معروض** (المخزن يبتلع الخطأ) | `Alert tone="danger"` + `error` في `deviceStore` |
| الفراغ | صف داخل الجدول بأيقونة ونص | `EmptyState` داخل `Card` مع زر إضافة |
| جدول | `glass` + ألوان صريحة | `border-line bg-surface` + رؤوس `text-muted` |
| حالة الاتصال | `span` بأصناف emerald/slate | `Badge` بنبرة `success`/`danger`/`neutral` |
| ألوان متبقية | 40+ صنفاً صريحاً | 4 فقط، كلها داخل كتل كود داكنة مقصودة (`bg-[#0a0f1e]`) |
| العرض الضيق | الجدول يُقصّ عند 398px (IP مبتور) | تمرير أفقي + `min-w-[620px]` |

**إضافة في المخزن:** `error: string | null` يُضبط عند فشل `fetchDevices` ويُصفَّر عند النجاح — كانت الأخطاء تُبتلع بصمت ويظهر جدول فارغ بدل رسالة.

## 3. ملاحظات من اللقطة (بصراحة)

1. عمود «اسم المضيف» يلتف على سطرين عند 398px — عولج بتمرير أفقي وحد أدنى للعرض، **لم يُتحقق بصرياً بعد التعديل** لأن نافذة المتصفح أُغلقت.
2. عنوان الصفحة يعرض «الأجهزة 1 · الأجهزة» — تكرار من نصوص i18n السابقة، ليس من التحويل.
3. الإجراءات داخل الصف تظهر عند التحويم فقط (`md:opacity-0`) — على شاشة لمس قد تحتاج إظهاراً دائماً؛ بند قابلية استخدام لاحق.

## 4. ما تبقّى

1. **بقية الشاشات** (بعد الأجهزة): غرفة العمليات، الشاشة، الجلسات، الإعدادات، المستخدمون، المساعد، المساعدة، الدخول، مساحة الجهاز (الملفات/الطرفية/المراقبة).
2. **حالات «انتهاء الصلاحية» و«النجاح»** لكل شاشة — الأدوات جاهزة، التطبيق بند لكل شاشة.
3. **`docs/UI-INVENTORY.md`**: عمود «يستخدم المكتبة» — الأجهزة الآن «جزئي» (الجدول والنموذج والحالات)، والبقية «لا».
4. **مراجعة 360/768/1280/1920** بعد اكتمال التحويل.
5. **فخّ التركيز في Modal** وتطبيقه في `AgentInstallModal`/`WolModal` (ما زالا نوافذ يدوية).
