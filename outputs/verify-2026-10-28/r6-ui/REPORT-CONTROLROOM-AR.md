# R6 — شريحة 7: جسر طبقة Control Room إلى الرموز

**التاريخ:** 2026-10-28 · **الحالة:** مُنفَّذ ومُتحقَّق بصرياً في الوضعين
**النطاق:** توحيد الطبقتين البصريتين (الرمزية الجديدة + `control-room.css`).

---

## 1. المشكلة

التطبيق كان يحمل طبقتين:

1. **`control-room.css`** (1928 سطراً، 255 استخداماً لـ`var(--cr-*)` + لون لوحة خاص `#071016`)، تحكم غرفة العمليات والأصداف.
2. **طبقة الرموز الجديدة** (`--surface/--line/--ink/...`) التي بُنيت عليها شاشات الأجهزة والجلسات والطابور.

النتيجة: صدفة داكنة شبه سوداء + لوحة تيل مستقلة، مقابل أسطح navy/فاتحة + تيل في الشاشات المحوّلة. مظهر «منتجين».

## 2. الحل

أُضيف في **نهاية** `control-room.css` كتلة جسر:

```css
:root {
  --cr-bg: rgb(var(--bg));
  --cr-panel: rgb(var(--surface));
  --cr-surface: rgb(var(--surface-2));
  --cr-line: rgb(var(--line) / .85);
  --cr-text: rgb(var(--ink));
  --cr-muted: rgb(var(--muted));
  --cr-teal: rgb(var(--primary));
  …
}
.app-rail   { background: rgb(var(--surface)) !important; }
.app-topbar { background: rgb(var(--surface) / .88) !important; }
```

لأن القواعد تأتي أخيراً، تفوز على التعريف الأصلي في `:root` وتحوّل **255 استخداماً** إلى مصدر اللون الواحد، بلا لمس أي JSX.

| غرفة العمليات — داكن (1440×900) | `shot-overview-dark.png` | صدفة navy موحّدة، لوحات أفتح قليلاً، تيل متسق، النص مقروء |

## 4. ما لم يتغيّر

- ألوان **حرفية** داخل `control-room.css` (مثل `rgba(255,255,255,.03)` و`#0c1720`) لا تمرّ بالمتغيّرات — بقيت كما هي. الجسر يغطي المتغيّرات فقط، وهو الأغلب (255 موضعاً).
- `html.light` في الملف نفسه يحمل قيماً فاتحة صريحة لبعض المكوّنات؛ تعمل، لكنها ليست من الرموز بعد.
- لقطات الشاشة لم تُفحص بعد على 360px/768px/1920px (البوابة لاحقاً).
