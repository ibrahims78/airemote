## 1. الطبقة الدلالية

**المشكلة:** الشاشات كانت تستخدم ألواناً صريحة (`bg-slate-900/40`، `text-slate-200`, `border-white/10`)، والسِمة تُبدَّل بإضافة `html.light` مع بقاء الأساس داكناً. أي مكوّن جديد يكتب ألواناً صريحة ينكسر في أحد الوضعين — وهو ما حدث فعلاً في المسودة الأولى لطابور النقل.

**الحل:** متغيّرات CSS في `index.css` هي مصدر الحقيقة، يقرأها Tailwind عبر `rgb(var(--…) / <alpha-value>)`:

| الرمز | الاستخدام | داكن | فاتح |
|---|---|---|---|
| `canvas` | خلفية الصفحة | `15 23 42` | `241 245 249` |
| `surface` | سطح البطاقة | `30 41 59` | `255 255 255` |
| `surface2` | سطح ثانوي/صف | `26 39 68` | `248 250 252` |
| `line` | الحدود والفواصل | `51 65 85` | `226 232 240` |
| `ink` | النص الأساسي | `241 245 249` | `15 23 42` |
| `muted` | النص الثانوي | `148 163 184` | `100 116 139` |
| `primary` | اللون الرئيسي | `59 130 246` | `59 130 246` |
| `success` / `warning` / `danger` / `info` | الحالات | … | … |

أُضيف كذلك `shadow-card`، `shadow-pop`، و`duration-fast` (120ms) لتمكين «ميزانية التفاعل < 100ms» لاحقاً.

**النتيجة:** لا يحتاج أي مكوّن لكتابة `dark:` أو ألوان صريحة؛ تبديل السِمة يغيّر المتغيّرات فقط.

## 2. مكتبة المكوّنات

`packages/dashboard/src/components/ui/` — 12 ملفاً:

| المكوّن | ما يوفّره |
|---|---|
| `Button` | 4 أنماط (primary/secondary/ghost/danger)، مقاسان، `loading` مع `aria-busy`، أيقونة، `forwardRef` |
| `Input` | حقل موحّد + حالة `invalid` + `aria-invalid` |
| `Select` | قائمة أصلية موحّدة |
| `Field` | تسمية + تلميح + خطأ (`role=alert`) + `required` |
| `Card` / `CardHeader` / `CardBody` | بطاقة بعنوان وتسمية فرعية وأفعال |
| `Badge` | 5 أنماط لونية للحالات |
| `Alert` | 4 أنماط + `role=alert` + إغلاق |
| `EmptyState` | حالة فارغة موحّدة (أيقونة/عنوان/وصف/فعل) |
| `ProgressBar` | مع `role=progressbar` و`aria-valuenow`، ووضع غير محدّد |
| `Skeleton` / `SkeletonRows` | هياكل تحميل ثابتة الارتفاع |
| `Modal` | `role=dialog` + `aria-modal` + Esc + نقر الخلفية + إعادة التركيز + قفل التمرير |
| `index.ts` | تصدير موحّد |

**التطبيق الأول:** أُعيد بناء `TransferQueue` بالكامل على المكتبة:
`Button` للأفعال، `Badge` للحالة، `ProgressBar` للتقدم، `Alert` للأخطاء وعدم التوفّر، `EmptyState` للفراغ، `Select` للتعارض والسرعة، ورموز `surface/line/ink/muted` للأسطح والنصوص. حُذفت كل أصناف `dark:` من المكوّن.

## 4. ما تبقّى من R6 (بصراحة)

1. **تطبيق المكتبة على بقية الشاشات** — الحالي: طابور النقل فقط. الباقي: الأجهزة، غرفة العمليات، الشاشة، الجلسات، الإعدادات، المستخدمون، المساعد، المساعدة، الدخول.
2. **حالات إلزامية لكل شاشة** (تحميل/فارغ/خطأ/نجاح/انتهاء صلاحية) — المكتبة توفّر الأدوات، والتطبيق بند لكل شاشة.
3. **RTL/LTR كامل** — الأساس موجود (`html.dir`)، ولم يُراجَع نص-بصرِياً.
4. **فخّ التركيز الكامل في `Modal`** — الحالي: Esc + إعادة تركيز + قفل تمرير؛ احتجاز Tab داخل النافذة بند لاحق.
5. **فحص تباين آلي AA** — لم يُنفَّذ؛ الألوان مختارة بتباين عالٍ لكن بلا قياس.
6. **جرد «100% من الشاشات»** — لم يُحدَّث؛ `docs/UI-INVENTORY.md` يحتاج أعمدة «تستخدم المكتبة».
