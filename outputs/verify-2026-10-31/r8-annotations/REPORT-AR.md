## 1) ما بُني

الليزر والتعليقات **لا تلمس الجهاز البعيد إطلاقاً**: أحداثها تُرحَّل بين مشاهدي الجلسة نفسها فقط.

| الطبقة | ما أُضيف |
|---|---|
| السيرفر | رسالة `screen:annotate` تُمرَّر إلى بقية مشاهدي الجلسة (بلا وكيل)، إحداثيات مُقيَّدة 0..1، لون مقطوع 16 حرفاً، معرّف خطّ، حدّ 240 حدثاً/ثانية لكل مقبس، ومقياس `airemote_annotation_events_total` |
| اللوحة | `AnnotationLayer.tsx`: طبقة SVG فوق الكانفاس بإحداثيات مُطبَّعة، ليزر يتلاشى (1.4s)، قلم ثابت، ممحاة، مسح الكل، أربعة ألوان |
| التفاعل | لوحة أدوات في الشريط + **L / P / E / C** للاختصار + Esc للخروج + شارة «وضع الرسم — التحكم البعيد موقوف» |
| الأمان | أثناء وضع الرسم تكون الطبقة هي المستقبِل (اختبار `elementFromPoint`)، فلا تصل أي أحداث فأرة/لوحة إلى الكانفاس ولا تُرسَل إلى الجهاز |

### البروتوكول

```
العارض → السيرفر → بقية العارضين
{ type: 'screen:annotate',
  payload: { tool: 'laser'|'pen'|'clear', id, phase: 'start'|'move'|'end',
             x, y,        // 0..1 بالنسبة للصورة المعروضة
             color, at } }
```

- **بلا وكيل:** الجهاز البعيد لا يعلم بوجود الرسم.
- **بلا حفظ:** لا قاعدة بيانات ولا ملف؛ تختفي العلامات بانتهاء الجلسة أو بإعادة الاتصال.
- **متعدد المشاهدين:** كل من يشاهد الجلسة يرى نفس العلامات في نفس الموضع مهما اختلف حجم نافذته.

## 3) عيب حقيقي كشفه الدليل البصري

البناء الأول كان يعمل برمجياً (46 حدثاً وصلت) لكن **لا شيء ظهر على الشاشة**: عنصر `<svg>` عنصر مُستبدَل بنسبة جوهرية 1:1 (viewBox `0 0 1 1`)، وبوجود `inset:0` وحده أخذ ارتفاعاً مساوياً للعرض (1329×1329) بدل 1329×560، فسقطت العلامات تحت حدود الصورة.

- الكشف: لقطة الشاشة (الحدث يمرّ، الأثر لا يُرى) — لا الاختبارات.
- الإصلاح: `width:100% · height:100%` صراحةً؛ القياس بعد الإصلاح: طبقة 1329×560 = الكانفاس تماماً.
- الدرس: اختبار البروتوكول لا يكفي لواجهة رسم؛ يجب لقطة + قياس صندوق العنصر.
