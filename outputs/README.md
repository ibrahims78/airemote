# مجلد المخرجات النهائية

هذا المجلد مخصص للمخرجات الجاهزة للتسليم أو العرض، مثل التقارير النهائية والملفات المولدة والحزم المؤرشفة.

## القواعد

- لا نضع هنا شيفرة المصدر ولا ملفات العمل المؤقتة.
- كل مخرج نهائي يجب أن يكون واضح الاسم ومؤرخاً عند الحاجة.
- حزم البناء والتوزيع الحالية تبقى في `releases/` لأن سكربتات البناء تعتمد على هذا المسار.
- عند إنشاء مخرج نهائي جديد، يُنسخ أو يُنقل إلى هنا مع تحديث `PROJECT_STATE.md`.

## ملاحظة

هذا المجلد أُنشئ ضمن توحيد البنية بتاريخ 2026-10-25. لا يحتوي حالياً على مخرجات جديدة.
