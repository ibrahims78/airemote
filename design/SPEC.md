## 3) خريطة الشاشات — كل عنصر موجود اليوم له مكان

### 3.1 السيرفر (اللوحة)

| العنصر الحالي | في التصميم | محفوظ؟ |
|---|---|---|
| شريط علوي: نظرة عامة/الأجهزة/المساعد/الجلسات/المساعدة/الإعدادات | شريط تنقل واحد (4 روابط أساسية + الباقي في قائمة التطبيق) | ✅ |
| بحث · تنبيهات (عدّاد) · قائمة المستخدم · قائمة التطبيق | نفس الأزرار في الشريط، أيقونات SVG | ✅ |
| جدار المراقبة: العدّاد `n/6` · S/M/L · إضافة بث | العنوان + العدّاد في الشريط الفرعي: مقاسات + «إضافة بث» | ✅ |
| لكل مربع: الاسم · شارة الحالة · تشغيل/إيقاف · تكبير · فتح · إزالة | نفس الستة في تذييل المربّع بنفس الترتيب | ✅ |
| مؤشرات (أجهزة متصلة/بث/تنبيهات) | ثلاث بطاقات قياس صغيرة | ✅ |
| حالات فارغ/تحميل/خطأ للجدار | شريط الحالات أسفل اللوحة (نفس الأنماط تُطبّق في مكانها) | ✅ جديد ظاهريًا، لا سلوك جديد |

### 3.2 وكيل ويندوز

| العنصر الحالي | في التصميم | محفوظ؟ |
|---|---|---|
| شريط النافذة: تصغير/إغلاق + شارة الاتصال | نفسها + شارة «متصل · v3.13.1» | ✅ |
| 3 تبويبات (التحكم عن بُعد · الاتصال بجهاز آخر · الجلسات) | نفسها | ✅ |
| التحكم عن بُعد: شارة الحالة · وضعان · حقل كلمة السر · قوة · حفظ · مسح · سطران توضيحيان | نفسها، في بطاقة واحدة | ✅ |
| عنوان الخادم · رمز الجهاز · زر البدء/الإيقاف | بطاقة «الاتصال بالخادم» + الشريط العلوي | ✅ |
| السجل + مسح | بطاقة «آخر الأحداث» بنفس زر المسح | ✅ |
| أيقونة الصينية (tray) · البدء التلقائي | **لا تُمسّ** — لا وجود لها في النموذج ولا تغيير عليها | ✅ |

### 3.3 وكيل أندرويد

| العنصر الحالي | في التصميم | محفوظ؟ |
|---|---|---|
| شريط الحالة + اسم الجهاز + الإصدار | رأس مضغوط + شارة «متصل» | ✅ |
| خدمة الإتاحة (مفتاح) | صف بمفتاح | ✅ |
| منح التقاط الشاشة (مفتاح) | صف بمفتاح | ✅ |
| كلمة سر التحكم (وضع + حالة) | صف بشارة «محمي · PBKDF2» | ✅ |
| الاتصال بجهاز آخر: الجهاز · الوصول · كلمة السر · الطلب | بطاقة كاملة بنفس الحقول | ✅ |
| الجلسات · السجل · إيقاف | شريط سفلي بثلاثة أزرار | ✅ |
| شاشات الإعداد/الاقتران/الإيقاظ (`SetupActivity`, `WakeActivity`) | **خارج نطاق النموذج** — تُطبَّق عليها الرموز نفسها لاحقًا بلا إعادة تصميم | ✅ |

**شرط التطابق:** أي عنصر في الجدول أعلاه يُنقل إلى التنفيذ كما هو؛ لا حذف، لا دمج، لا تغيير سلوك.

## 4) خطوات التنفيذ (بالترتيب، بأثر مرئي)

| # | العمل | الملفات | البوابة |
|---|---|---|---|
| 1 | إدخال الرموز كمتغيّرات CSS | `agent/renderer/index.html` (block `:root`) · `dashboard/src/index.css` | لا لون/مقاس خارج الرموز |

## 5) ما يُقاس بعد التنفيذ

- `check-contrast` ≥ 22/22 (لا ينخفض).
- `audit-screen-surface --check` = PASS (11 زرًا في الشريط، 0 فتح مباشر).
- `typecheck` + `build` PASS · البطارية 46/46.
- لقطات قبل/بعد للشاشات الثلاث عند نفس المقاس (1644×539 · 560×746 · 390×676).

## 6) حدود التصميم (بصراحة)

- النموذج يغطّي **الشاشات الأساسية** الثلاث، لا كل شاشات المنتج (إعدادات، اقتران، إيقاظ، ملفات). الباقي يتبع الرموز نفسها بلا إعادة تصميم.
- لا يضيف أي ميزة جديدة؛ كل ما فيه موجود اليوم أو حالة عرض (فارغ/تحميل/خطأ).
- الأرقام في النماذج **توضيحية**، وليست بيانات حقيقية.
