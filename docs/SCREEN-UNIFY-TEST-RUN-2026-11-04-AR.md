## 2) مشغّل المتصفح (الفتح الأهم في هذه الجولة)

`outputs/verify-2026-11-04/control/tools/cdp-driver.cjs`

- Chrome + CDP خام؛ لا Playwright في المستودع.
- **الرمز يُقرأ من `tools/lab/.token.json` داخل Node ويزرع في `localStorage` — لا يُطبع ولا يمرّ في أي مخرجات.**
- `process.env.HEADED='1'` يفتح نافذة مرئية (الافتراضي بلا واجهة).
- الاستخدام: `const d = require('./cdp-driver.cjs')` ثم `launch()` → `attach()` → `goto/evaluate/shot`.

### مصائد وقعنا فيها (لا تُعِدها)

1. **الـhook يُمسح عند التنقّل**: أي `window.WebSocket` معدَّل قبل `Page.navigate` يزول. ثبّته **بعد** تحميل الصفحة.
2. **`innerText` لا يرى `title`**: أزرار الشريط تعرض أيقونات فقط. طابقها بـ`title` أو `aria-label`.
3. **«إيقاف البث» ≠ «إيقاف التسجيل»**: الأول يقتل الجلسة ويُخفي أثر التسجيل.
4. **عدّ الأسطر التاريخية**: `input-worker.log` يعود لساعات سابقة؛ احسب الفرق بين `COUNT` قبل وبعد فقط.
5. **البث يُطلق بزر «بدء مشاركة الشاشة»** داخل تبويب «الشاشة»؛ فتح التبويب وحده لا يكفي.
6. **canvases كبيرة ليست دليل بث**: الرسوم البيانية تُنشئ canvas أيضًا؛ الحكم القاطع هو عدد اتصالات `/screen`.

`packages/server-desktop/static/assets/ScreenViewer-BECNyttN.js` (87,230 بايت — وهي الحزمة التي يقدّمها السيرفر فعلًا):

```
... e.pointerType==="mouse" && e.button===2) {
      D("down", e.clientX, e.clientY, 2),
      D("up",   e.clientX, e.clientY, 2),
      a.downX = e.clientX, a.downY = e.clientY, a.moved = !1, a.dragging = !1, ...
```
