# التفويض للمساعدين (Subagents) — قيود البيئة وسير العمل المعتمد

**آخر تحديث:** 2026-11-02 · **السياق:** 3.11.7 · مُثبت بتجارب مضبوطة (لا استنتاج).

---

## 1) المشكلة كما قيست

| # | الحقيقة | الدليل الحرفي |
|---|---|---|
| 1 | **أدوات ملفات المساعد محصورة في مجلد مساحة العمل** ولا تصل إلى `D:\` | `Tool blocked: tool_permission_revoked — Path D:\... is outside the workspace C:\...\projects\Default; file tools read and write only inside it` |
| 2 | **الوصلة (junction/symlink) مرفوضة صراحةً** | `Tool failed: workspace_path_denied — the path resolves through a symbolic link; give the real path inside the workspace` |
| 3 | **الوكيل المؤقت (temporary) بلا `exec` إطلاقاً** | `هذه الجلسة بلا أداة shell/exec` |
| 4 | **الوكيل المحفوظ الذي يملك `exec`** ينفّذ أمراً مسموحاً ويصل إلى `D:\` | `Get-Content 'D:\...\VERSION'` ⇒ أعاد `3.11.7` |
| 5 | الأوامر المتعددة/غير المسموحة تفشل مغلقة | `subagent_execution_failed` (بعد إعادات) |

**النتيجة:** «نقل المشروع إلى C:» ليس حلاً كاملاً: يمنح القراءة فقط، ويكلّف **194 إشارة مسار مطلق في 96 ملفاً**، ويُبقي أدوات البناء على `D:\` والأجهزة على `E:\`، ولا يمنح المساعدين تنفيذاً.

## 2) الحل المعتمد: مرآة المصدر

```powershell
# من داخل مجلد مساحة العمل (وليس من المستودع)
node "D:\autoclaw projects-new\AiRemote\tools\lab\a2a\mirror-sync.cjs"
node "D:\autoclaw projects-new\AiRemote\tools\lab\a2a\mirror-sync.cjs" --check
```

- **الناتج:** `<workspace>\mirror\src` + `INDEX.txt` + `META.json` — **457 ملفاً · 10.2 MB · 0.9 ثانية**.
- **لا ينسخ:** `node_modules` · `dist` · `releases` · `outputs` · `build` · `.gradle` · `.git` · أي ملف سرّي.
- **`--check`:** يطابق بصمات الملفات الحرجة (`server.js` · `ScreenViewer.tsx` · `AgentService.java` …).

**تحقق مُنجز (2026-11-02):** وكيل بلا `exec` قرأ `mirror/src/packages/server-desktop/server.js` (5,925 سطراً) وأعاد `RELAY_MAX_SESSIONS` (سطر 1823) و`RELAY_CHANNELS` (1827) و`relayResumeForDevice` (2302) بدقة.

## 3) توزيع الأدوار

| نوع المهمة | مَن ينفّذها | الآلية |
|---|---|---|
| تحليل كود · مراجعة · مقارنة · صياغة وثائق · مخططات | أي وكيل (`分析师` · `文档撰写师` · `数据可视化师` · `研究员`) | يقرأ `mirror/src` |
| أمر قراءة **مفرد** على المستودع (`Get-Content` · `rg` لملف) | وكيل يملك `exec` (`研究员` · `审阅者` · `执行者`) | أمر واحد مسموح |
| بناء · تثبيت · adb · VMware · قياسات · Git | **الجلسة الرئيسية فقط** | لا تفويض |
| تطبيق أي تعديل على المستودع | **الجلسة الرئيسية** عبر `patch.cjs` | يرفض التكرار أو الانكماش |

**قبل كل موجة تفويض:** حدّث المرآة (0.9 ثانية). **بعد كل تعديل في المستودع:** أعد التحديث قبل التفويض التالي.

**حدود صريحة:** المرآة قراءة فقط ⇒ المساعد لا يكتب في المستودع ولا يشغّل اختبارات؛ أي «تنفيذ» يبقى في الجلسة الرئيسية.

## 4) قالب بريف ناجح

```
المهمة: راجع <ملف> في mirror/src/<path> وأعد <عدد> نتائج.
الحدود: قراءة فقط، لا تعدّل، لا تشغّل أوامر.
المخرَج: لكل نتيجة سطر <اسم>: <قيمة> (سطر N) — بلا شرح زائد.
```

قالب فاشل: «افحص المشروع وأصلح ما تجده» — يتطلب `exec` وكتابة خارج المسموح ⇒ `subagent_execution_failed`.

## 5) أخطاء شائعة يجب تجنّبها

1. إرسال مسار `D:\...` داخل البريف — الطفل سيحاول فيُمنع؛ **مرّر المسار النسبي داخل المرآة**.
2. تكليف طفل ببناء/اختبار — لا يملك `exec`؛ النتيجة فشل عام لا رسالة واضحة.
3. الاعتماد على وصلة/اختصار — مرفوض صراحةً.
4. نسيان تحديث المرآة بعد تعديل الكود ⇒ تحليل على كود قديم بأرقام أسطر خاطئة.

## 6) أين تعيش هذه الوثيقة ولماذا

القيود أعلاه مقيسة على مضيف ويندوز هذا (PowerShell 5.1 · AutoClaw). عند تغيّر المنصة أو منح المساعدين صلاحيات أوسع، **أعد القياس** قبل الاعتماد على هذه القواعد — لا تفترض بقاءها.
