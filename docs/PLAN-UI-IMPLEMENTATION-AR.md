## 1) الهوية البصرية (البصمة)

**الفكرة:** «غرفة عمليات هادئة» — سطح واحد واضح، لون تمييز واحد، حالة كل شيء مرئية بشارة لا بنص.

| العنصر | القيمة |
|---|---|
| اللون المميز | فيروزي `#0f766e` (فاتح) / `#2dd4bf` (داكن) — لا لون ثانٍ للتمييز |
| الحالات | نجاح `#047857`/`#34d399` · تحذير `#b45309`/`#fbbf24` · خطر `#dc2626`/`#f87171` |
| الطباعة | 11px ثانوي · 13px أساسي · 16px عنوان — **لا مقاس رابع** |
| الشبكة | 4px (4 · 8 · 12 · 16) — لا مسافة خارجها |
| نصف القطر | 8px للأزرار والحقول · 12px للبطاقات |
| الأيقونات | `lucide` بسماكة 1.6 · 14px (12 داخل الأزرار الصغيرة) · **لا إيموجي** |
| الحركة | 120–180ms · `ease-out` · لتغيّر الحالة فقط |
| البصمة المميزة | **شارة حالة + عنوان + سطر وصف** في رأس كل بطاقة، وشريط حالات (فارغ/تحميل/خطأ) في كل سطح |

**التباين المُقاس (WCAG):** 9/9 PASS في الوضعين؛ أدنى قيمة 4.54:1 (نص خافت على خلفية فاتحة). بعد تصحيح لون النجاح من 3.77 إلى 5.48.

### 2.2 قواعد إلزامية

1. **إجراء رئيسي واحد** لكل سطح (زر واحد بـ`primary`).
2. **≤ 3 كلمات** لكل تسمية زر؛ التفصيل في `hint`.
3. كل بطاقة تبدأ بـ**شارة حالة**.
4. لا `style="..."` مضمّن — كل شيء عبر الأصناف.
5. كل سطح له **4 حالات**: طبيعي · فارغ · تحميل · خطأ.

## 6) كتالوج الرسائل (نبرة موحّدة)

### 6.1 القواعد

- الجملة تبدأ بالفعل، وتقول **ما حدث + ما تفعله الآن**.
- لا لوم، لا «خطأ غير معروف»، لا أكواد خامة للمستخدم.
- كل رسالة خطأ تحمل: سببًا + إجراءً (زر).
- الرسائل القصيرة: ≤ 60 حرفًا للنجاح · ≤ 120 للخطأ.

### 6.2 نماذج ملزمة

| الحالة | عربي | English |

| نجاح حفظ الإعدادات | حُفظت الإعدادات | Settings saved |

## 12) ما أحتاجه منك للموافقة

1. **اعتماد المرجع البصري:** الملفات الثلاثة + صورها هي «الحقيقة» التي تُقاس عليها المطابقة.
2. **قرار الثيم الافتراضي:** فاتح (كما في الصور) — وأؤكد أن الداكن يبقى متاحًا بمتغيّر واحد.
3. **اعتماد كتالوج الرسائل (§6)** أو تعديل أي نص.
4. **تأكيد النطاق:** الصفحات العشر وتبويبات الوكلاء الأربعة موجودة في النماذج؛ المرحلة 4 تُكمل **محتواها الحقيقي** (219 عنصرًا) وتُعرض لقطاتها قبل الاعتماد.
5. **الموافقة على الجرد (§5)** بعد أن أُصدره كملف CSV.

> بعد موافقتك: أبدأ بالمرحلة 0 وأسلّم الجرد أولًا — لا أكتب سطر واجهة قبل أن تُصدّق على أنه لا زر ناقص.
