## 2) عائق مفتوح (البند 1 — نقرة تنزيل تفاعلية)

جلسات `files` **تُغلق تلقائيًا خلال ~دقيقتين** بلا أي مشاهد WS ⇒ تذكرة `rt` (60ث) ومفتاح `rk` يبطلان، والنافذة تُغلق قبل النقر.
**الحل المقترح:** keep-alive لجلسات الملفات (نبضة دورية من الصفحة/الوكيل تُبقي الجلسة، أو رفع `RELAY` TTL للجلسات النشطة بإطار `files`).

## 3) المتبقي

1. إصلاح إغلاق جلسات files ثم إعادة محاولة النقر التفاعلي.
2. PoC نفق Cloudflare (بانتظار: نقل NS، API Token، إذن LTE).
3. مسار CRD (TURN/WebRTC).

## 4) الفخاخ الحديثة

- بعد تعديل `server.js`: **`node scripts/bundle.js`** قبل حزم asar.
- `AGENT_CA_CERT` مطلوب لتشغيل وكيل ويندوز يدويًا.
- جلسة files مع `rt` عمرها 60ث؛ استخدم `rk` (12س) للروابط الطويلة.
- مسار الجذر `C:\` محظور كتابةً في طبقة fs (`EPERM mkdir 'C:\'`).
