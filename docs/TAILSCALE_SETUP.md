# الاتصال عبر Tailscale (الخيار م2) — دليل التشغيل

> هذا هو المسار المعتمد للوصول عن بُعد في AiRemote: **شبكة خاصة مشفّرة (WireGuard) بعنوان ثابت
> — بدون فتح منافذ في الراوتر، وبدون تعريض الخادم للإنترنت العام.**

## لماذا Tailscale؟

| الميزة | ماذا تعني عملياً |
|---|---|
| عنوان ثابت | عنوان `100.x.y.z` (أو اسم MagicDNS) لا يتغيّر — لا حاجة لتحديث الوكلاء عند إعادة التشغيل |
| بلا فتح منافذ | لا NAT، لا Port Forwarding، لا نفق عام — الخادم غير مرئي للإنترنت |
| تشفير كامل | كل الاتصال بين الأجهزة يمر عبر WireGuard مشفّراً من الطرف للطرف |
| مجاني للاستخدام الشخصي | حتى 3 مستخدمين و100 جهاز على الخطة المجانية |

## المتطلبات

1. حساب Tailscale (تسجيل مجاني: <https://tailscale.com>).
2. تثبيت تطبيق Tailscale على **كل** جهاز سيتصل:
   - جهاز السيرفر (الذي يشغّل AiRemote Server Desktop)
   - كل جهاز عليه وكيل AiRemote
   - أجهزة التحكم (لابتوب/هاتف للمشاهدة)

## الخطوات

### 1) السيرفر
1. ثبّت Tailscale وسجّل الدخول بنفس الحساب.
2. خذ عنوان الجهاز: من لوحة Tailscale أو بالأمر:
   ```
   tailscale ip -4
   ```
   مثال: `100.101.102.103`
3. شغّل **AiRemote Server Desktop** كالمعتاد (يستمع على المنفذ 3001 لكل الواجهات).
   > لا تحتاج لتشغيل نفق Cloudflare إطلاقاً في هذا الوضع — أوقفه إن كان يعمل.

### 2) أجهزة الوكلاء
1. ثبّت Tailscale وسجّل الدخول بنفس الحساب، وتحقق أن الجهاز يظهر في لوحة Tailscale.
2. في وكيل AiRemote، ضع عنوان السيرفر:
   ```
   ws://100.101.102.103:3001/ws?agent=1
   ```
   (مع توكن الجهاز كما هو في الإعداد الحالي)
3. اختبر الاتصال: من جهاز الوكيل:
   ```
   ping 100.101.102.103
   ```
   إن نجح الـping فالاتصال الشبكي جاهز.

### 3) جهاز التحكم (اللوحة)
افتح المتصفح على:
```
http://100.101.102.103:3001
```

## اختيارياً: اسم ثابت بدل الأرقام (MagicDNS)
فعّل MagicDNS من لوحة Tailscale، وستحصل على اسم مثل:
`server.tail1234.ts.net` — استخدمه بنفس الطريقة:
```
ws://server.tail1234.ts.net:3001/ws?agent=1
```

## ملاحظات أمنية

- **لا تفتح المنفذ 3001 في الراوتر** — الوصول عبر Tailscale فقط.
- كل جهاز منضم إلى شبكتك يستطيع الوصول للمنفذ 3001 — إن أردت تقييداً أدق، استخدم
  [ACL policies](https://tailscale.com/kb/1018/acls) في لوحة Tailscale (وسوم وسياسات وصول).
- احتفظ بحساب Tailscale محمياً بـ2FA — هو مفتاح الشبكة بأكملها.

## استكشاف الأخطاء

| المشكلة | الفحص |
|---|---|
| الوكيل لا يتصل | تأكد أن Tailscale يعمل (`tailscale status`) على الطرفين وأن الـping ناجح |
| الوكلاء يرون السيرفر، واللوحة لا | جرّب `http://100.101.102.103:3001/api/health` من متصفح جهاز التحكم |
| توقف مفاجئ | بعض شبكات الهاتف توقف الاتصالات الطويلة — أعد فتح Tailscale على ذلك الجهاز |

## Quick English note
Install Tailscale on the server, every agent machine and your control device (same account).
Point agents to `ws://<tailscale-ip>:3001/ws?agent=1` and open `http://<tailscale-ip>:3001`
for the dashboard. No port forwarding, no public tunnel — stable IPs and full WireGuard
encryption. Recommended over the Cloudflare Quick Tunnel for daily use.
